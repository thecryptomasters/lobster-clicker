# Lobster Clicker — Visual Freeze Checklist

Freeze candidate: 2026-09-01

The visual system is frozen for launch-candidate QA. New visual work after this point should fix a defect, improve accessibility/readability, or address playtest evidence rather than introduce a new art direction.

## Frozen systems

- [x] Polished neo-80s seaside arcade direction.
- [x] Coral, cyan, gold, seafoam, and violet status palette.
- [x] Bungee display typography and Atkinson Hyperlegible UI typography.
- [x] Arcade score cabinet, navigation, buttons, panels, and building cards.
- [x] Large illustrated claw with a frame-by-frame pinch animation.
- [x] Nine illustrated building cabinets.
- [x] Upgrade, card, offline-return, milestone, and achievement medallions.
- [x] Capsule Catcher and Lobster Card presentation.
- [x] Theatrical Molting presentation.
- [x] Progression-reactive Harbor Empire with nine building landmarks.
- [x] Living water, fog, boat, buoys, lights, stars, and moon.
- [x] Reduced-motion behavior.
- [x] Steam capsule/library family and six honest 1080p screenshots.

## Freeze verification

- [x] Fresh and extreme late-game saves at six browser resolutions.
- [x] Buildings, Upgrades, Boosts, and Molt tabs.
- [x] Keyboard, mouse, and touch input.
- [x] Real card draw, offline-return report, and Molt sequence.
- [x] Transparent animation edges and responsive claw framing.
- [x] No console or page errors in the exported browser suite.

## Allowed pre-launch changes

- Correct visual defects, clipping, contrast, inaccurate copy, or input regressions.
- Adjust animation timing or effect intensity in response to playtests.
- Replace store assets only if Ross rejects a specific candidate.
- Do not add new progression systems, currencies, buildings, or a different art direction before 1.0.
